Semantic reuse through the demo dashboard, 2026-11-25 (F28)

Purpose: first end-to-end run of the semantic reuse feature through the Streamlit dashboard
(demo step 7), on real models.

Code: gateway as of commit 1315542 (320 offline tests), demo step 7 as committed in 804e2fa.
Models (Ollama): answers llama3.2:3b; embeddings nomic-embed-text:latest; judge qwen2.5:7b.
All three were reported "100% GPU" by `ollama ps` on 2026-11-24 (generation context 4096,
embedding context 2048; Ollama unloads a model after 5 minutes idle by default).

Gateway (fresh databases):
  Remove-Item demo-data.db*, demo-llm.db* -ErrorAction SilentlyContinue;
  uv run --env-file .env python -m multi_agent_ai_systems --http 8000 --edgar
      --llm-model llama3.2:3b --db demo-data.db --llm-db demo-llm.db
      --semantic semantic-team=active --semantic-show-log --min-similarity 0.8
Dashboard:
  uv run --group demo streamlit run demo/dashboard.py
Step 7 asks two questions in workload semantic-team (max_tokens 300): the first, then the
second, and reads the gateway's decision for the second from gateway_stats (recent log).
