Judge evaluation on the development set, 2026-11-25 (F29)

Purpose: measure how well embedding similarity, the reject-only rules and an LLM judge separate
question pairs whose earlier answer can be reused from pairs where it cannot.

Data: bench/pairs.jsonl v0.2, the development set: 58 single short question pairs, 22 labelled
direct_answer_reuse=true and 36 false (labels defined in bench/README.md). Written by Claude and
reviewed with ChatGPT and Liu. Thresholds and the judge prompt were tuned on it, so these
results are not evidence of performance elsewhere.

Script: bench/judge_eval.py. Calls the models directly through Ollama's OpenAI-compatible API,
not the gateway. For every pair it computes cosine similarity of the two questions
(nomic-embed-text:latest), runs the rules, and always calls the judge, so the judge can be
measured alone. "rules, then judge" is the gateway's chain: a rule's DIFFERENT wins, otherwise
the judge's verdict. "reuse" at a floor = similarity >= floor and the chain says SAME.

Runs, in order:
  A. qwen2.5:7b judge, rules and judge prompt as of commit 1315542
  B. llama3.2:3b judge, same rules and prompt as A
  C. qwen2.5:7b judge after two changes made because of run A (commit e6ce328):
     - the modal-verb rule ignores "can/could/would/will you" and "how can"
       (A rejected s18 and s21 for "modal verbs differ")
     - the judge prompt lists "length, language or unit" as answer requirements
       (aimed at d23; it did not change d23's verdict)
Command: uv run python bench/judge_eval.py --judge-model <model>
bench/results/judge-qwen2.5_7b-2026-11-25.jsonl holds run C (run A's file was overwritten).
bench/results/judge-llama3.2_3b-2026-11-25.jsonl holds run B, made with the old rules.
